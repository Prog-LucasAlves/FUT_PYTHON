# Projeto de Análise de Estratégias de Apostas Esportivas

## Visão Geral

Este projeto tem como objetivo analisar a viabilidade de diferentes estratégias de apostas esportivas utilizando dados da Betfair. O projeto utiliza notebooks Jupyter para implementar e testar as estratégias, e ferramentas de qualidade de código para garantir a manutenibilidade do código.
